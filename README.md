he College Placement Dashboard is an interactive Power BI project designed to analyze and visualize student placement data. It provides insights into placement rates, eligible and placed students, company-wise hiring, department-wise performance, salary packages, and year-wise placement trends.

The dashboard uses Power Query for data cleaning and transformation and DAX for creating calculated measures and KPIs. Interactive charts, slicers, and cards allow users to filter and analyze placement performance based on academic year, department, company, gender, and placement status.

Key features:
📊 Overall placement rate and placement statistics
🎓 Department-wise placement analysis
🏢 Company-wise student recruitment
💰 Highest, average, and lowest salary packages
📈 Year-wise placement trends
👨‍🎓 Placed vs. unplaced student analysis
🔍 Interactive filters and slicers
📌 KPI cards for quick performance monitoring
